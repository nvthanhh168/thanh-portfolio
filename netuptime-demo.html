🔒 Mã bí mật được bảo vệ & ẩn hoàn toàn khỏi màn hình. Để trống nếu không muốn thay đổi.
Đăng ký URL này vào Web Redirect URI trên portal Microsoft
Chỉ cho phép nhân viên có đuôi email này đăng nhập
📋 Hướng dẫn đăng ký ứng dụng trên Microsoft Entra ID (Azure AD):
  1. Truy cập entra.microsoft.com $\rightarrow$ Applications $\rightarrow$ App registrations $\rightarrow$ Bấm New registration.
  2. Đặt tên ứng dụng (vd: NetUptime Sentinel SSO), chọn Single tenant, thêm Redirect URI loại Web: http://localhost:8090/api/auth/m365/callback (hoặc IP mạng LAN).
  3. Tại trang Overview, copy Application (client) ID và Directory (tenant) ID dán vào 2 ô tương ứng ở trên.
  4. Vào mục Certificates & secrets $\rightarrow$ New client secret $\rightarrow$ Copy chuỗi Value dán vào ô Client Secret.
